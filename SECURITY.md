# Seguridad

Si encuentras un fallo de seguridad (por ejemplo, una clave publicada por error o algo que permita manipular las APK), **no abras un issue público**.

Usa el aviso privado de GitHub: pestaña **Security → Report a vulnerability** de este repositorio. Solo lo ve el responsable del proyecto.

Las APK oficiales se publican únicamente en [Releases](../../releases) de este repositorio. No instales APK de Mazmorreo de otras fuentes.
