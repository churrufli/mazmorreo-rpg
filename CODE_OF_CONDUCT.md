# Código de conducta

Mazmorreo sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/). En resumen:

## Lo que esperamos

- Trato respetuoso y amable, también en las críticas.
- Aceptar con buena disposición las correcciones y otros puntos de vista.
- Centrarse en lo mejor para el proyecto y para la comunidad.

## Lo que no se acepta

- Insultos, acoso, comentarios discriminatorios o ataques personales.
- Lenguaje o imágenes sexuales fuera de lugar.
- Publicar datos privados de otras personas sin su permiso.
- Cualquier conducta que no sería apropiada en un entorno profesional.

## Cómo avisar

Si ves algo que incumple estas normas, escribe al responsable del proyecto mediante el aviso privado de seguridad de GitHub (pestaña **Security → Report a vulnerability**) o abre un issue sin dar detalles personales. Se revisará con discreción.

El responsable puede borrar comentarios, cerrar issues o PR y bloquear a quien incumpla estas normas.
